# Code of conduct

This project is for everyone who wants the parliamentary record to be easy to read and search,
whatever their politics, language, background or skill.

## Our standards

- Be respectful and patient. Many volunteers are new to GitHub.
- Talk about the work, not the person.
- Do not use this project to campaign for or against a party or a Member of Parliament.
  The text is the official record. We do not add opinions, summaries or labels to it.
- No harassment, insults, threats, or sharing of other people's private information.

## What maintainers do

Maintainers can edit or delete comments, close discussions, and block accounts that break these rules.
To report a problem, open a private report to the maintainers through the repository's
**Security** tab ("Report a vulnerability"), or contact a maintainer on their GitHub profile.

This code is based on the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
